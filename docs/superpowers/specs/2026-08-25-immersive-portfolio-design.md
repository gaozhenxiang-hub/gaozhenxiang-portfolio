# 双世界沉浸式个人作品集网站设计规格

- 日期：2026-08-25
- 状态：用户已批准整体设计
- 主要场景：桌面端求职展示与个人作品集
- 核心定位：用网站本身证明审美能力、视觉创作能力和 Vibe Coding 能力

## 1. 项目目标

网站不是传统简历页，也不以详细解释多模态视频评测岗位或项目过程为重点。它应被体验为一件可交互的个人数字作品：访客先进入暖白色艺术展厅浏览作品，再穿过明暗转场进入深色 3D 数字展厅。

成功体验需要同时满足：

1. 第一眼具有强烈但克制的视觉辨识度。
2. 鼠标拖动、滚动和点击都能影响空间，而非只有装饰性光标尾迹。
3. 5–7 个视觉作品能够快速浏览，其中 2–3 个重点作品获得更沉浸的 3D 展示。
4. 项目说明保持极简，图片、视频和动态预览是主要内容。
5. 网站能体现实现复杂视觉创意的能力，同时不让访客迷路或遇到黑屏。

## 2. 非目标

首版不包含以下内容：

- 大篇幅项目复盘或传统案例研究页面。
- 以目标岗位、履历年表或技能清单为中心的信息结构。
- 博客、内容管理后台、登录系统或服务端业务功能。
- 为手机单独设计一套同等复杂的 3D 体验。
- 直接复制参考网站的品牌、模型、贴图、音乐、文案或作品素材。

## 3. 核心概念：明暗双世界

### 3.1 暖白艺术展厅

网站开场和普通作品浏览使用暖白偏灰的空间。背景具有细颗粒或胶片质感，两侧存在原创的拱门、柔软浮雕、半透明薄片和少量缓慢漂浮的纸片或蝶形元素。画面边缘可出现克制的彩虹折射与 RGB 色差。

作品以双列大画幅卡片组成展墙。整体排版清晰、留白充足，黑色极简文字与彩色作品画面形成对比。背景、浮雕、漂浮物和作品墙具有不同的视差速度。

### 3.2 深色 3D 数字展厅

重点作品位于可穿行的黑色 3D 隧道或数字展厅内。环境以黑色、炭灰、银色、玻璃、镜面金属、半透明薄膜和发光线条为主。彩色光仅来自折射边缘、粒子、作品屏幕和交互反馈。

该空间应具备电影感，而不是常见的紫色渐变或赛博朋克模板。作品画面是空间中最鲜艳、最重要的视觉主体。

## 4. 完整浏览流程

1. **轻量加载阶段**：显示简洁的加载状态；暖白首屏可用后立即进入，深色 3D 资源在浏览作品墙时继续后台加载。
2. **身份开场**：只显示姓名或个人代号和一句极简定位，不展示人物照片。实际名称与定位文案从内容配置读取。
3. **精选作品墙**：展示 5–7 个图片、视频、视觉设计或生成式内容作品。普通项目只显示名称、年份、类型标签和大幅动态封面。
4. **明暗转场**：到达重点作品入口时，暖白空间出现裂缝、黑色画框或空间入口。继续滚动后镜头穿入深色区域。
5. **3D 数字展厅**：滚动控制前进与后退，鼠标拖动控制有限范围的观察方向。2–3 个重点作品成为悬浮屏幕、光幕或巨大画框。
6. **全屏作品查看器**：点击作品后，以高清图片或视频为主体，只显示作品名、年份和类型，并支持前后切换。详细说明作为默认隐藏的可选入口。
7. **极简收尾**：回到清晰的黑白页面，只保留结束语、邮箱、社交链接和简历入口。

右上角始终提供声音开关、画质选择、作品导航、跳过 3D 和返回作品墙入口。

## 5. 交互设计

### 5.1 鼠标移动与拖动

- 自定义光标具有轻微延迟；接近作品时扩大并显示简短动作提示。
- 暖白展厅中，按住拖动改变作品墙和背景空间的观察角度；松开后保留短暂惯性并平滑停止。
- 深色展厅中，按住拖动改变镜头朝向，但限制旋转角度，避免用户失去方向。
- 拖动判定与点击判定分离，短按仍可可靠地打开作品。

### 5.2 滚动与转场

- 暖白区域使用自然纵向滚动。
- 明暗转场区将滚动进度映射到入口打开、环境变暗和镜头推进。
- 深色展厅中滚动控制沿预设路径前进或后退。
- 任何阶段都不得完全锁死用户，必须保留跳过和返回方式。

### 5.3 作品反馈

- 普通作品悬停时产生景深、边缘折射和 3–8 秒静音动态预览。
- 重点作品接近时，环境灯光响应作品主色，但不覆盖作品原色。
- 全屏播放器避免大量文字和传统弹窗感，切换动作延续当前空间方向。

### 5.4 声音

- 默认静音，刷新后不得突然播放。
- 用户主动开启后，仅播放低强度环境音、空间转场声和轻微交互音。
- 声音状态由固定控制项明确显示。

## 6. 视觉系统

- 主色：暖白、近黑、炭灰、银色。
- 强调色：只在折射、色差、光线、粒子和作品反光中出现的光谱色。
- 中文字体：简洁、现代、字形偏窄的黑体方向。
- 英文字体：中性无衬线方向，可在标题转场中使用少量拉伸或错位动画。
- 卡片：大画幅、轻微圆角、极细边框，不使用传统投影式组件效果。
- 动态质感：景深、模糊、颗粒、光晕和色差均保持克制；不能持续遮挡作品。

## 7. 内容模型

每个作品记录包含：

- 唯一标识
- 名称
- 年份
- 单个类型标签
- 高清封面
- 3–8 秒循环预览媒体
- 全屏展示媒体
- 是否进入重点 3D 展厅
- 可选的极短说明与外部链接

作品内容集中存放在单一配置层中，页面和 3D 场景只读取数据，不写死具体项目。用户尚未提供的姓名、定位、联系方式、简历和作品素材必须使用明确的中性占位标识，不能编造经历、客户、指标或作品。

## 8. 技术架构

推荐技术栈：

- Next.js App Router + React + TypeScript：页面结构、路由和内容层。
- React Three Fiber + Three.js：暖白空间、3D 隧道、材质、灯光与摄像机。
- GSAP：明暗转场、镜头轨迹、作品展开和复杂时间线。
- Lenis：桌面端平滑滚动，并与 GSAP/3D 进度同步。

主要模块边界：

1. `SiteShell`：全局导航、声音、画质和跳过控制。
2. `IntroGallery`：身份开场与暖白背景。
3. `ProjectWall`：根据作品配置生成双列作品墙与预览。
4. `PortalTransition`：把滚动进度转换为明暗转场状态。
5. `TunnelGallery`：管理 3D 场景、受限镜头路径和重点作品位置。
6. `ProjectViewer`：全屏媒体展示和作品切换。
7. `QualityManager`：画质模式、能力检测和必要时的保护策略。
8. `AudioManager`：默认静音、用户授权后的环境音与交互音。

模块之间通过当前区域、滚动进度、选中作品、画质模式和声音状态通信。作品媒体和文案只从内容配置进入展示模块。

## 9. 高画质与性能策略

桌面端以高画质为默认目标：完整 3D 材质、玻璃折射、阴影、景深、光晕和粒子优先启用。图片使用高清源，视频优先提供高质量桌面版本。

画质控制包含：

- `HIGH`：桌面默认，完整效果。
- `AUTO`：根据持续帧率和设备能力自动调整昂贵但不影响内容的效果。
- `LITE`：用户手动选择的轻量版本。

优化首先通过模型与纹理压缩、资源分段、按需加载、后台预加载和视频格式选择完成，而不是直接牺牲画质。只有浏览器不支持或持续明显卡顿时，才减少粒子、反射、景深或渲染分辨率。

## 10. 响应式与可访问性

主要验收尺寸为 1440×900 和 1920×1080。手机端不是主要创作对象，只需保证作品、导航和联系方式可以正常访问；触摸滑动替代鼠标拖动，并缩短 3D 隧道。

同时提供：

- 可键盘访问的导航和作品入口。
- 跳过 3D 体验的固定入口。
- 对系统“减少动态效果”偏好的基础响应。
- 视频静音预览和清晰的声音状态。

## 11. 错误处理

- WebGL 初始化失败时切换到同风格的 2D 视差背景，作品墙仍可浏览。
- 重点 3D 场景未加载完成时显示明确进度，不允许黑屏。
- 单个视频失败时回退到高清封面，不阻断其他作品。
- 单个模型或纹理失败时隐藏对应装饰，并保留导航与内容。
- 反复进入和退出作品查看器时释放不再使用的媒体与 3D 资源。

## 12. 验证与验收

- 在最新版 Chrome 和 Edge 桌面端验证完整流程。
- 在 1440×900 与 1920×1080 下检查作品不被错误裁切或变形。
- 验证拖动惯性、点击判定、滚动前后退、跳过 3D 和返回作品墙。
- 验证默认静音、声音切换、刷新状态和媒体自动播放限制。
- 验证 `HIGH / AUTO / LITE` 切换后视觉状态稳定。
- 模拟 WebGL、视频、模型和纹理加载失败，确认不会出现不可恢复黑屏。
- 反复打开和关闭作品，检查无持续显存增长、重复音频或失效控制。
- 对最终媒体进行桌面高清视觉检查，重点关注压缩、色带、模糊和颜色偏移。

## 13. 原创与授权边界

参考网站只用于提取设计语言：暖白空间、双列作品墙、电影级 3D、鼠标拖动和明暗转场。实现时重新设计空间造型、模型、纹理、声音、文案、图标和动效节奏。任何第三方素材在使用前必须核验授权；开源代码许可不自动覆盖图片、模型、纹理、字体、音乐或品牌资产。

## 14. 实施前内容输入

开始填充真实内容前，需要用户提供或确认：显示名称、极简定位、5–7 个作品的媒体与基本信息、2–3 个重点作品、联系方式、社交链接和简历文件。缺失内容不阻止先搭建结构，但所有临时内容必须明确标记为占位，且能从统一配置中快速替换。
